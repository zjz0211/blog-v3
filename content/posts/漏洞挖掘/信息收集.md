# 前言—为什么要进行信息收集？

**信息收集，是漏洞挖掘中的“态势感知”。换句话说：渗透测试的本质就是信息收集。**
它决定了你后续的每一步是“精准打击”还是“盲目扫射”。没有信息收集的渗透测试，本质是在用未知对抗未知——你不知道目标的架构、版本、组件，就无法调用对应的攻击向量。信息收集不是可选项，而是决定漏洞产出效率的**前置变量**。
# 一、域名信息收集
## 1、域名介绍

互联网中的每台服务器（如网站、邮件服务器等）都有唯一的数字标识——IP地址（如192.168.1.1或更复杂的IPv6地址）。但数字难以记忆，于是域名应运而生，通过将IP地址“翻译”成易读的文字（如zjz946649.top），降低了用户访问的网络门槛。
```
www.baidu.com   # 百度官网
tieba.baidu.com  # 百度贴吧
```
## 2、域名分类

**（1）主域名：** 主域名是域名体系中最核心、最基础的部分，通常由“二级域名+顶级域名”组成，是用户注册时的核心标识。

**（2）子域名：** 子域名是在主域名基础上，通过前缀扩展形成的次级域名，用于区分主域名下的不同服务、板块或功能。

![](/images/20260806122704.webp)

**标识网站属性：** `.com`代表商业机构、`.edu`代表教育机构、`.gov`代表政府机构等。
**标识地域归属：**`.cn`代表中国、`.jp`代表日本等。

## 2、绕过CDN的方式
### 2.1 什么是CDN
CDN即内容分发网络。CDN是构建在网络之上的内容分发网络，依靠部署在各地的边缘服务器，通过中心平台的负载均衡、内容分发、调度等功能模块，使用户就近获取所需内容，降低网络拥塞，提高用户访问响应速度和命中率

![](/images/20260806205437.webp)

如果发现多地ping存在多个IP地址，那么该IP地址是CDN的IP地址，并不是真实的IP地址

**（1）查询子域名的IP**

## 3、端口信息收集
### 3.1 什么是端口
端口（Port）是一种软件抽象概念，它是计算机内部网络通信进程的一种标识，用于区分不同的应用程序或服务，一台计算机的端口是0-65535之间

![](/images/20260806211011.webp)
### 3.2 端口扫描

端口扫描就是向目标服务器的各个端口发送探测包，根据返回的响应来判断该端口是否开放、运行了什么服务。这是信息收集中非常关键的一步——**端口即服务，服务即攻击面**。扫描到开放的端口，就等于找到了可以尝试攻击的入口。

**常用工具：Nmap（业界标准）**

Nmap 是端口扫描的首选工具，Kali Linux 自带，Windows 也可安装。

**（1）基础扫描命令**

```bash
nmap 目标IP地址
```

直接输入目标 IP，Nmap 会默认扫描 **1000 个最常用端口**，并返回端口号、状态（open/closed/filtered）以及服务名称。

**（2）常用参数组合（新手建议记住这一个）**

```bash
nmap -sV -sC -p- 目标IP地址
```

| 参数 | 含义 |
|------|------|
| `-sV` | 探测端口上运行的服务及**版本号**（这对漏洞挖掘至关重要） |
| `-sC` | 使用默认脚本扫描，自动检测常见漏洞和信息 |
| `-p-` | 扫描**全部 65535 个端口**（不加的话只扫 1000 个常用端口） |

**（3）只扫指定端口**

```bash
nmap -p 80,443,8080,3306,3389,22,21 目标IP
```

**另一利器：Masscan（极速端口扫描）**

Nmap 虽然功能强大，但扫描全部 65535 个端口时速度较慢，可能耗时数十分钟甚至更久。Masscan 号称"互联网级端口扫描器"，能在 **几分钟内完成全端口扫描**，因为它采用异步无状态扫描技术，不对每个连接维护状态，速度可达 Nmap 的百倍以上。

**常用命令：**

```bash
masscan -p1-65535 目标IP --rate=1000
```

| 参数 | 含义 |
|------|------|
| `-p1-65535` | 扫描全部端口（也可用 `-p80,443,3306` 指定） |
| `--rate=1000` | 每秒发包速率，内网可调高到 10000+，外网建议 500-1000 避免触发防火墙 |

**配合 Nmap 使用：**

Masscan 和 Nmap 各有所长——Masscan 快但信息少，Nmap 慢但信息全。最佳实践是**先用 Masscan 快速找出所有开放端口，再用 Nmap 对开放端口做深度版本探测**：

```bash
# 第一步：Masscan 快速扫全端口，输出开放端口列表
masscan -p1-65535 目标IP --rate=1000 -oL open_ports.txt

# 第二步：Nmap 针对开放端口做服务版本识别
nmap -sV -sC -p 端口列表 目标IP
```
**常见的危险端口及对应服务**

| 端口        | 服务           | 漏洞挖掘方向             |
| --------- | ------------ | ------------------ |
| 21        | FTP          | 匿名登录、弱口令爆破         |
| 22        | SSH          | 弱口令爆破、私钥泄露         |
| 80/443    | HTTP/HTTPS   | Web 漏洞（SQL注入、XSS等） |
| 3306      | MySQL        | 弱口令、未授权访问          |
| 3389      | RDP（远程桌面）    | 弱口令爆破、MS17-010     |
| 6379      | Redis        | 未授权访问（可写 Webshell） |
| 8080/8443 | HTTP 代理/管理后台 | 后台弱口令、默认密码         |
| 445       | SMB          | 永恒之蓝（MS17-010）     |
| 1433      | MSSQL        | 弱口令、sa 账户爆破        |
## 4、C段信息收集

### 4.1 什么是C段

IP 地址由 4 组数字组成（如 `192.168.1.100`），每组范围 0-255。**C 段指的是 IP 地址的前三组数字相同、最后一组不同的地址范围**，也就是 `192.168.1.0` ~ `192.168.1.255` 这 256 个 IP 地址。举个例子：

```
主站 IP：110.42.98.156
C 段范围：110.42.98.0 ~ 110.42.98.255
```

同一机构或公司购买的服务器，往往会集中在同一个 C 段内。比如一个学校的官网、选课系统、OA 系统，IP 地址很可能都是 `110.42.98.x`，只是最后一组数字不同。

```
110.42.98.156  →  主站（官网）
110.42.98.158  →  后台管理系统
110.42.98.165  →  邮件服务器
110.42.98.170  →  测试服务器（可能有漏洞）
```

### 4.2 为什么要收集C段信息

收集 C 段信息的目的很直接——**通过一台已知服务器，顺藤摸瓜发现同一机构下的其他资产**。这些"旁站"往往安全防护比主站薄弱很多，可能存在：

- 测试服务器忘记关闭，开放了高危端口
- 老旧系统未及时打补丁
- 管理后台用了默认密码
- 开发环境直接暴露在公网

### 4.3 C段扫描方法

**（1）Nmap 扫描整个 C 段**

拿到目标 IP 后，直接用 Nmap 对 C 段做端口探测：

```bash
nmap -sV -p 80,443,8080,22,3306 110.42.98.0/24
```

`/24` 表示子网掩码 255.255.255.0，即扫描该 C 段全部 256 个 IP。

**（2）Masscan 快速扫描 C 段**

如果 C 段较大或需要全端口扫描，用 Masscan 更快：

```bash
masscan -p80,443,8080,3306,22 110.42.98.0/24 --rate=1000
```

**（3）在线工具查询**

不想用命令行时，以下网站可以快速查询 C 段上的其他站点：

- **[FOFA](https://fofa.info/)**：`ip="110.42.98.0/24"`
- **[在线C段查询](https://www.ipip.net/)**：输入 IP 可直接查看同网段资产
**（4）TxPortMap工具**
1、下载工具
```
wget https://gitee.com/yijingsec/TXPortMap/releases/download/v1.1.2/TxPortMap_linux_x64 -O TxPortMap
```
2、修改运行权限
```
chmod +x TxPortMap
```
3、运行工具
```
./TxPortMap -i IP或者域名/24 -p 80
```

# 五、搜索引擎高级语法

## 1、谷歌语法
谷歌语法的作用，谷歌作为最大的搜索引擎`www.google.com`，利用其强大的搜索能力可以方便快捷的找到我们需要的信息，例如：子域名、后台管理地址、敏感信息、以及可能存在漏洞的网页
### 1.1 语法
#### （1）限制搜索范围
- site：限制你搜索域名的范围，将搜索范围限制在某网站或顶级域名中
- “关键词”：给关键词加上半角引号实现**精确搜索**
- 通配符 * ：必须在半角双引号内使用，用通配符代替关键词中无法确定的字词， * 前后需要加空格
- 布尔逻辑：
	- 逻辑与：and（其实 Google 默认就是"与"逻辑，多个词空格分隔即可，不用特意写）
    【A and B ：检索同时含有A和B的内容】
	- 逻辑或：OR（必须大写，写成 `|` 或小写 or 都不生效）
    【A OR B：检索包含关键词A或B的内容】
	- 逻辑非：-
    【去掉相关检索内容】
#### （2）高级搜索
- intitle：标题搜索  即搜索页面中title标签包含关键字的页面
- intext：内容(正文)搜索
- inurl：对url进行限制，搜索URL中含有关键字的内容    例：`inurl:robots.txt、inurl:8080/ inurl:jsp`
- filetype：对文档类型进行限定   真正支持的类型有限（pdf、doc、xls、ppt、rtf、txt等），conf、inc、mdb 这类基本搜不到，建议用 inurl 代替
- site：搜索范围限制在某网站或顶级域名中
![](/images/20260716132238.webp)

**注意：** 2024 年起 Google 对 `intitle:`、`inurl:` 这类运算符的支持变得不稳定，单独使用大多有效，但与其他普通关键词混用时偶尔会被忽略（结果里会出现不包含该条件的内容）。搜不到预期结果时，可以改用 `site:` + 关键词，或者换 Bing 搜索。

# 六、ARL灯塔扫描
## 1、什么是ARL灯塔
ARL 灯塔（全称 Asset Reconnaissance Lighthouse，资产侦察灯塔系统）是一款专为网络安全领域设计的自动化资产发现与风险评估工具，核心功能是帮助安全团队、渗透测试人员快速定位目标组织的互联网资产（如域名、IP、端口、Web 应用等），并通过多维度扫描识别潜在漏洞和攻击面

## 2、灯塔安装条件
**条件1：** Kali中安装内存必须大于4G，灯塔比较吃资源，内存不够启动不起来
![](/images/20260807130704.webp)
**条件2：** 服务器必须有网络，并且确保域名能解析
```
ping baidu.com
```
![](/images/20260807130705.webp)
**条件3：** 必须找到服务器对应的IP地址，如果是VPS就是用公网IP
```
ifconfig
```
![](/images/20260807130706.webp)

## 3、ARL灯塔安装
1、下载安装LinuxEnvConfig并且启动
```
git clone https://gitee.com/yijingsec/LinuxEnvConfig.git
cd LinuxEnvConfig
sudo bash LinuxEnvConfig.sh
```
运行后脚本会弹出配置菜单，选择"配置 ARL"
![](/images/20260807130707.webp)
2、选择1安装灯塔
![](/images/20260807130708.webp)
3、输入IP地址，公网VPS输入公网的，Kali输入本地的
![](/images/20260807130709.webp)

![](/images/20260807130710.webp)
